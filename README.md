# CloudflareSub

一个基于 **Cloudflare Workers**
的轻量级订阅生成工具，用于整理节点链接并生成多种客户端可用的订阅格式。

该项目适合个人部署、自用或学习 Cloudflare Workers 的基本开发方式。

------------------------------------------------------------------------

# 功能

-   支持输入多个节点链接
-   支持批量替换服务器地址为指定 IP 或域名
-   自动生成多个客户端订阅格式
-   支持二维码生成，方便移动端导入
-   支持基础去重处理
-   支持 Cloudflare Workers 一键部署

当前支持的订阅格式：

-   原始节点订阅
-   Clash 订阅
-   Surge 订阅

## 多用户订阅管理

访问 `/admin.html`，输入 `SUB_ACCESS_TOKEN` 后加载配置。全局只维护有顺序的**公共优选 IP**，节点全部保存在各个用户名下。

1. 保存公共优选 IP：每行一个 IP 或域名，可填写 `IP:端口#备注`。优选时从第一行开始取，调整行顺序即可调整优先级。
2. 新建用户或编辑已有用户，填写名称和订阅名称。
3. 选择节点链接或 Clash YAML，粘贴后点击“添加到此用户”。可批量导入，导入后每个节点独立编辑。
4. 为每个节点选择是否使用优选 IP，数量可选“全部”或“前 N 个”。关闭优选时只输出原节点；开启后输出 `名称-0`（原地址）和 `名称-1…N`（优选地址）。公共列表不足 N 个时使用现有数量，列表为空时保留 `名称-0`。
5. 点击“预览生成节点”核对名称、协议和地址，再保存用户。客户端刷新原订阅链接即可生效。

优选不限制传输协议，WS、XHTTP 等均可开启。副本保留 UUID、密码、TLS、SNI、Host、路径和协议设置；公共地址指定端口时覆盖节点端口，否则沿用原端口。若输入没有显式指定 Host/SNI，副本会保留原服务器作为相应的默认握手目标。开启优选并不代表服务端已支持 CDN，请按服务端实际配置选择。

链接导入支持 VLESS、VMess、Trojan、Hysteria2。YAML 支持单个节点、节点列表或带 `proxies` 的配置，其他配置段不会导入；Reality、XHTTP、Hy2 等节点的完整 YAML 参数会保留。**包含 YAML 节点的组合请使用 Clash 订阅**；原始链接输出仅用于全部由链接导入的组合。无法完整转换的格式会提示错误，不会悄悄省略节点。

每个用户独立存储节点，若多人使用相同 Hy2，分别导入同一份配置即可。这里是订阅内容的独立配置，管理后台仍共用一个管理员令牌。

### 旧配置迁移

首次加载管理后台时，旧 WS 链接转换为开启“全部优选”的个人节点，旧模板按用户 UUID 转换，共享 Hy2 和个人 YAML 分别复制到各用户的节点列表。所有已有订阅 ID 保留。迁移完成后公共配置只包含优选 IP 和用户索引，新用户不会继承旧共享节点。

KV 中保留 `backup:v1:config:global` 和 `backup:v1:profile:<用户ID>` 作为迁移前备份。迁移会先解析旧数据，解析失败时不删除旧配置；成功后重复加载不会再次复制节点。旧静态订阅仍可使用。

### 本地验证

```sh
npm ci
npm run check
npm run dev
```

测试涵盖协议参数保留、按顺序取 N 个 IP、用户隔离、旧数据迁移、订阅链接保留和非法配置拒绝。运行 `npm run deploy` 部署到已配置的 Cloudflare 账户。
